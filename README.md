### ЗАДАНИЕ 3. «Формулировка рекомендаций»

#### Шаг 3.1. План мероприятий по устранению уязвимостей (в порядке приоритета)

| Приоритет | Проблема | Рекомендация | Ответственный | Срок |
| :---: | :--- | :--- | :--- | :---: |
| **1** | **SQL-инъекция** | Провести аудит кода, использовать prepared statements | Разработчик | 3 дня |
| **2** | **Устаревшая CMS** | Обновить WordPress до актуальной версии (6.4+) | Системный администратор | 2 дня |
| **3** | **Нет HTTPS** | Установить SSL-сертификат (Let's Encrypt) | Системный администратор | 1 день |
| **4** | **Открытая панель** | Скрыть URL админки, включить капчу | Системный администратор | 3 дня |
| **5** | **Нет 2FA** | Включить двухфакторную аутентификацию | Системный администратор | 5 дней |
| **6** | **Нет сертификата** | Получить сертификат у провайдера и настроить его автопродление | Системный администратор | 2 дня |
